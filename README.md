### Demand Estimation, Cost Analysis & Competitive Positioning
**Course Final Project | 2019–2023 | Amazon Purchase Data**

## Project Overview
This project analyzes the market for air fryers using brand-year data aggregated from Amazon purchases. We move from descriptive analysis to a demand model, then use that model to infer unit costs, markups, and profitability for the top 10 brands from 2019–2023.

---

## Repository Structure

| File | Description |
|------|-------------|
| `air_fryers_clean_brand_year.csv` | Cleaned dataset — top 10 brands, 2019–2023, shares sum to 1 within each year |
| `Part1_DataAnalysis_EDA.ipynb` | Data analyst role: EDA, visualizations, market description |
| `Part2_DemandEstimation.ipynb` | Data scientist role: logit demand model estimated via linear regression |
| `Part3_Strategy.ipynb` | Pricing analyst role: inferred unit costs, markups, and share-weighted profit |
| `Part4_AirFryer_Market_Intelligence.pptx` | Business presentation: market intelligence summary (9 slides) |
